# Mobile assets

Bu klasör fontlar, icon, splash görselleri için ayrılmıştır.

## Beklenen dosyalar (henüz eklenmedi)

- `icon.png` (1024×1024)
- `adaptive-icon.png` (1024×1024, Android)
- `splash.png` (1284×2778, koyu zemin)
- `notification-icon.png` (96×96 monochrome, Android)
