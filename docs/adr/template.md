# NNNN — Karar başlığı

| Durum | Tarih | Sahip |
| --- | --- | --- |
| Taslak / Kabul Edildi / Değiştirildi (→ NNNN) | YYYY-MM-DD | Kişi veya ekip |

## Bağlam

Kararı gerektiren problem ve kısıtlar. Kod yolu ve commit/PR referansı ver.

## Karar

Seçilen yaklaşım, tek paragraf.

## Sonuçlar / Riskler

Kazanılanlar, ödenen bedel, bilinen riskler. Gerekçe koddan veya commit geçmişinden
çıkarılamıyorsa bunu açıkça yaz: "Gerekçe koddan çıkarılamadı, ilgili kişiyle teyit edilmeli."

## Kanıt

- `dosya/yolu.ts` — ilgili kod
- `abc1234` — commit veya PR
